# Stay Stronger — Quiet Artistry Redesign

A complete visual redesign of the original Stay Strong daily challenge tracker.

## Features
- Daily completed / missed check-ins and status clearing
- Current and longest streak calculations
- Calendar month navigation and date selection
- Achievement milestones
- Challenge end-date settings
- Light and dark themes
- Automatic local-device saving
- Responsive layout and reduced-motion support

## Data compatibility
This redesign deliberately retains the original localStorage key (`nnnChallengeTrackerDataV1`) and the same state fields. It can read saved progress when opened on the same browser and origin. Browser storage is scoped by origin; GitHub Pages projects under the same account domain share the origin.

The app does not upload personal progress to a server. Clearing browser site data or using another browser/device may remove or hide locally stored progress.

## Run locally
Open `index.html` in a modern browser, or publish the repository with GitHub Pages.

## Design
Quiet Artistry: warm editorial surfaces, wine and olive accents, restrained line-art decoration, upright typography, readable contrast, responsive spacing, and reduced-motion support.
